Vincule o WhatsApp do celular à Cloud API sem perder o aplicativo no aparelho.

Atenção: Abra esta página via HTTPS (ex: pelo link do seu ngrok ou domínio com SSL) e preencha os dados do Meta for Developers. O backend (Spring + ngrok) precisa estar no ar antes de clicar em Conectar, porque o code expira rápido e a sincronização do histórico só pode ser pedida uma vez.
